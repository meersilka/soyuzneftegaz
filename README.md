# Сайт ООО «СоюзНефтеГаз»

Каталог трубопроводной арматуры и металлопроката. Челябинск.

## Стек

Чистый HTML, CSS и JavaScript без сборки и без зависимостей. Открывается
двойным кликом по `index.html` — сервер не нужен, шрифты встроены в файл стилей.

```
index.html     каркас страницы
styles.css     дизайн-система и все компоненты
app.js         экраны, маршрутизация, логика расчётов
data.js        номенклатура металлопроката
data-arm.js    трубопроводная арматура, фланцы, опоры
assets/        логотип, шрифты, карточка партнёра
```

Маршруты живут в адресной строке после решётки: `#/catalog`, `#/product/<артикул>`,
`#/calc` и так далее — на любую страницу можно дать прямую ссылку.

## Что умеет

Каталог с фильтрами по группе и типу, карточка позиции с пересчётом тонн
в метры, штуки и листы, калькулятор теоретической массы, разбор присланного
списка позиций, корзина с расчётом счёта, личный кабинет с ролями.

Складские остатки на сайте не показываются: объём на складе — внутренняя
информация, по ней отвечает менеджер. Позиции без цены идут «по запросу».

## Статус

Демонстрационная версия. Цены в `data.js` — заполнитель, до выгрузки из
учётной системы; у позиций, добавленных по коммерческому предложению, цены
нет совсем. Поэтому сайт закрыт от индексации (`robots.txt` и `noindex`
в `index.html`); обе строки снимаются, когда появятся боевые данные.
