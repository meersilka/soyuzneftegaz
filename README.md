# Сайт ООО «СоюзНефтеГаз»

Каталог металлопроката и трубопроводной арматуры со склада в Челябинске.

## Стек

Чистый HTML, CSS и JavaScript без сборки и без зависимостей. Открывается
двойным кликом по `index.html` — сервер не нужен, шрифты встроены в файл стилей.

```
index.html     каркас страницы
styles.css     дизайн-система и все компоненты
app.js         экраны, маршрутизация, логика расчётов
data.js        номенклатура металлопроката
data-arm.js    трубопроводная арматура, фланцы, опоры
assets/        логотип, шрифты, карточка партнёра
```

Маршруты живут в адресной строке после решётки: `#/catalog`, `#/product/<артикул>`,
`#/calc` и так далее — на любую страницу можно дать прямую ссылку.

## Что умеет

Каталог с фильтрами по группе, типу и складу, карточка позиции с пересчётом
тонн в метры, штуки и листы, калькулятор теоретической массы, подбор позиций
по смете, корзина с расчётом счёта, личный кабинет с ролями и лимитами.

## Статус

Демонстрационная версия. Цены и остатки в `data.js` — заполнитель, до выгрузки
из учётной системы. Поэтому сайт закрыт от индексации (`robots.txt` и `noindex`
в `index.html`); обе строки снимаются, когда появятся боевые данные.
